# PlagiarismGuard Assets

Place the following files in this directory:

| File      | Description                                      |
|-----------|--------------------------------------------------|
| logo.png  | App logo (recommended: 200×60 px, transparent PNG) |
| bg.jpg    | Background image (optional, used as fallback bg) |

The CSS handles the dark animated background automatically even without bg.jpg.
The logo.png is optional — the text hero renders fine without it.
